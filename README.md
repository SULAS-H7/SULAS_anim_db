# SULAS Animal Dataset

## Overview

The **SULAS (Setsunan University Laboratory of Animal Science) Animal Dataset** is a collection of fecal microbiota sequencing data from various mammalian species, generated through research conducted at our laboratory.

This dataset integrates data from both previously published studies and unpublished research conducted by our laboratory. It was compiled to facilitate comparative analyses of gut microbial communities across mammalian species. All samples were processed using standardized protocols for fecal sample collection, DNA extraction, library preparation, and 16S rRNA gene amplicon sequencing, as previously described (Kobayashi et al., 2020: PMID 32285557), ensuring methodological consistency across the data.

## Dataset Description

The dataset includes fecal microbiota sequencing data collected from various mammalian hosts.

The collection comprises:

- **Published data:** Sequencing data generated in previous studies conducted by our laboratory and reported in peer-reviewed publications.
- **Unpublished data:** Sequencing data generated by our laboratory that have not yet been formally published.
